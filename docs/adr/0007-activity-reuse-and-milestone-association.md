# 活动可跨月龄阶段复用，里程碑显式声明关联活动

活动库采用「活动 ↔ 阶段」多对多关系：一个活动声明自己的适用月龄阶段范围（如"俯卧抬头"适用 [2,3,4,5] 个月），跨阶段复用同一内容。这符合真实育儿场景（同一练习持续数月）并大幅压缩内容生产量（20 阶段约 200+ 活动可压缩至 60~100 个核心活动）。

里程碑与活动的关联采用**显式声明**而非按能力领域自动聚合：每个里程碑列出自己的关联活动清单，累计次数只统计这些活动的完成次数。避免"领域活动过多导致阈值轻松达成"的失真，也保持每个里程碑的阈值可独立配置。

活动字段含安全提示（垫软垫、全程看护等），作为必要的免责边界。
