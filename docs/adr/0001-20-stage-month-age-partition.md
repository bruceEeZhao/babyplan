# 月龄阶段采用「0-12 按月、13-36 按季」的 20 阶段划分

月龄划分决定内容生产粒度与产品信息架构。调研了 BabySparks、Kinedu、Lovevery 及 CDC/WHO/卫健委等权威机构的划分惯例后，确定：0~12 个月精确到每个自然月（12 个阶段），13~36 个月每 3 个月为一个阶段（8 个阶段：13-15、16-18、19-21、22-24、25-27、28-30、31-33、34-36），共 20 个阶段。

选型依据：0~1 岁发育速率极快（每个月都有显著能力变化），按月划分与 CDC/卫健委的里程碑检查频率一致；1 岁后发育节奏放缓，医疗与消费产品（Lovevery 玩具订阅）均采用 3 个月粒度。细分方案（每 2 个月一阶段）被否决，因为内容生产量增幅大而用户感知差异小。
